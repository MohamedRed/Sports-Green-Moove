# Private Phone Input

Read this before any approved manual phone trial that uses temporary credentials.
The native phone is streamed through a browser canvas: host focus, canvas focus,
the phone browser address bar and the intended field are different surfaces.
Coordinates alone do not establish which surface will receive a key.

## Before Sensitive Input

1. Focus only the intended field, then obtain a fresh phone observation. Do not
   batch a coordinate click, clearing shortcut and credential entry together.
2. Confirm the intended field's visible focus, label, masking and settled keyboard
   layout. Re-observe after any scrolling, keyboard transition or tab change.
3. Do not use `super+a`, `Meta+A`, `Command+A` or another global selection shortcut
   to replace a secret on the streamed phone. Clear an already verified field
   with bounded individual Backspace keys, then observe that it is empty and
   remains focused before entering the replacement.
4. Keep credentials in private memory only. Do not put passwords in URLs, host
   clipboard, command arguments, public recordings, screenshots or tool output.
   During entry, suppress image output; observe only after masking is complete.
5. If the recipient or focus is uncertain, do not send the next credential key.
   Rehearse the intended focus/clearing sequence with non-secret text first.
   A local-browser rehearsal cannot prove the streamed phone's input routing.

For the next separately approved invitation attempt, run the mismatch check with
two public, non-secret placeholders before revealing any fixture password.
Record the independent zero-redemption observation, then reload that same private
form through its normal browser control. Observe all three fields blank before
entry. Enter the actual credential only into freshly focused empty fields, never
by replacing the mismatch with a secret through a selection shortcut. This
candidate sequence has not yet been verified on another phone.

## Wrong Destination

Stop immediately. Do not submit the address bar or reuse the credential. Clear
the visible unintended field without displaying its value. Treat autocomplete
transmission as possible, even if navigation was never submitted. Destroy the
entire owned local dataset, stop its connection and phone, restore the host
clipboard, and verify owned processes, listeners and private inputs are absent.
If any real credential is involved, stop and obtain the required owner-led
rotation instead; local-fixture disposal cannot invalidate a real credential.

Retain sanitized negative records and the original incomplete outcome. Do not
retain or publish the sensitive frame or value. Record honestly if sensitive
tool output occurred; excluding it from the repository does not erase that output.
Do not call the incident an app or network defect without supporting evidence.
Any new phone/private connection trial requires the applicable fresh approval.
