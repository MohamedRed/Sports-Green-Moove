# Contracts

This folder is the source of truth for app/backend interfaces used by iOS, Android, Firebase Functions, and the admin console.

- `data-model.md`: Firestore, Realtime Database, and Storage model.
- `auth.md`: Firebase Auth role claims and trusted authorization shape.
- `api.md`: callable functions, webhooks, and expected payloads.
- `matching.md`: deterministic carpool matching rules.
- `tracking.md`: Radar, native fallback, and live ride contracts.
- `payments.md`: Stripe Connect and reward ledger behavior.
