The b0 candidate places its role-bound presentation model in shared child-account
DTOs. The existing strict callable signature harness fails because that narrow
gateway compilation does not include UI account scope. The original failure log
is retained. No test mock, signature harness, compiler flag or test is weakened.

Move the exact enum/guard bytes to ChildAccountPresentation.swift. Shared DTOs
return to their earlier wire-only source; the actual native plan explicitly
compiles the new presentation file and executes its existing role/identity checks.
The unchanged strict signature harness and full local native plan then both pass.
Before/after logs and content-addressed current sources are retained. Native
subprocess stdout interleaves; the raw output is not reconstructed.

The item-based sheet, constructor authorization and eleven UI cases retain their
behavior. Corrected SDK/UI, physical device, operational, safety and release
acceptance remain open. This follow-up adds no public headline or new media.
