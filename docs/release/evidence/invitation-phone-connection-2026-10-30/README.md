isolated APK hash is retained in summary.json; installed bytes are not independently
hashed. The user approved adding only loopback port 4185 for this trial. The
default four-service helper scope remains unchanged, with a separate explicit
approved flag for the five-port trial. No public server, broad routing, MITM,
request logging, paid upgrade or new provider resource was enabled.

instead shows ERR_CONNECTION_REFUSED for both 127.0.0.1:4185 and localhost:4185.

retained, not published. The Local toolbar was enabled with Resolve all URLs
disabled earlier in the session. This is not proof that all later requests
reached the helper. Its worker ultimately exited with code zero without a
requested stop. No recorded close timestamp establishes whether that exit
preceded either browser error; the worker correctly rejects it as an unverified
shutdown. The error's transport/root cause is not proven.

invitation, zero redemption attempts, zero new child accounts, zero approval

missing private-fixture-input guard before connecting; the corrected invocation

link secret was entered on the phone. These records do not prove rendered UI,
sharing, signup, approval, payments, physical tracking or release completion.

The invitation used the existing isolated service fixture, not a fresh invitation
created through the native parent share sheet. Even a successful local browser
entry would not prove the unpublished production link works. Earlier native
sharing and desktop browser proof retain their original dates and scope.

The provider returned to Uploaded Apps with no active stop-session control and
the owned tab closed. The uninstall flow reached a confirmation, but completion
and package absence were **not** independently verified; no uninstall success is

The host clipboard was restored. The helper group exited and its temporary
directory is absent. The owned runtime exited, removed both private handoffs,
destroyed its isolated environment and verified all five service ports closed.

An alias-based retry needs its own explicitly scoped permission and a fresh
trial. No alias was enabled in this retained attempt. Official setup and
