# Selected Ride Observation Services

The original completed local run executed seven groups through real authenticated
callables against isolated emulators. Two active rides verified that an explicit
observer id stays bound to its selected ride, including after completion. The
default discovery endpoint can still return the other active ride; that is not a
substitute for the selected observer response.

The remaining groups checked missing-point metadata, capture age/source fields,
outsider and unauthenticated denial, invalid references/payloads, and a remote
pickup reflected in the parent's response. The administrative client closed
before the positive report was written, the script exited zero and every owned
emulator stopped. Raw reports/transcripts and exact source archives are retained.

These are API/storage checks, not Android screen, real GPS, network-loss recovery,
provider delivery or release acceptance. The native screen trial is independently
gated and cannot be accepted from these seven groups. No production write,
customer data, real payment or paid provider request was used.
