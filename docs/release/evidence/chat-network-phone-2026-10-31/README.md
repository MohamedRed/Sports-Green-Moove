# Controlled Chat Retry On A Physical Phone

31 October 2026, one Google Pixel 9 Pro / Android 15.0 in App Live. The existing
isolated APK is selected by its retained filename and local SHA-256. Remote
installed bytes are not independently attested. Synthetic accounts and disposable
local services only; no production data, real payment or map request.

An isolated service fixture creates a free adult booking and no chat messages.
The parent signs in on the phone, chooses that booking and opens its empty
conversation. The provider's Offline Mode is applied before the first send.
The phone displays an unconfirmed-send error and retains the exact text.
Independent records still contain zero messages and zero chat notifications.

After network simulation is disabled, the phone still shows the unconfirmed
text, and the independent zero-message checkpoint passes before retry. One
explicit phone retry stores one parent message, one notification and two exact
conversation indexes. The controller then sends exactly one driver reply using
an authenticated SDK actor. The phone receives and reads that reply. This is a
real parent UI exchange with a service-driven peer, not two-phone proof.

Eight independent checkpoints verify exact message/request identities, bodies,
recipients, notification counts, read state and index unread counts. Every
foreign conversation, non-chat collection, account claim and live-trip snapshot
is preserved, except the documented parent initialization timestamp. The driver
reply does not pretend to read the parent's message: the driver's unread state
is preserved. A controlled cutoff before sending is not post-commit response
loss or real-world radio loss during travel.

Four reviewed original session crops are published: unconfirmed text, connection
restored before retry, one confirmed message, and the received test reply. Seven
original 216 by 457 session crops are retained unchanged. These are not native
device exports or video. The older simulated captures, dates and two-step tour
remain available after the new four-step phone tour. Messages stays partial.

The parent signs out. The provider acknowledges successful uninstallation and
returns to the idle device dashboard after session closure. Package absence is
not independently measured. Network simulation is observed disabled, the host
clipboard is restored and the remote clipboard has harmless synthetic text.
No test-phone administrator policy is changed. Observer, backend and private
helper exit; their directories, credential input and four service ports are
independently absent or closed.

Physical radio/GPS tracking, process restart, peer phone UI, push delivery, iOS,
actual payments, full native-gate acceptance and release remain separate. This
trial does not fix or explain earlier capture-copy or connection failures.
No infrastructure change is required. Public access to the partner site stays
unchanged. Only the four reviewed synthetic images are published.
