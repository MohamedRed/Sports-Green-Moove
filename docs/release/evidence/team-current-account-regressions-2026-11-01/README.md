# Team Current-Account Regression Trials

1 November 2026. Five fresh, independent local runtime trials pass after the
shared team-authority correction: conversation (18), directory (6), reads (12),
generic alerts/pending envelopes (11), notification inbox (7). All 54 cases pass.
Protected baselines and original account claims remain intact in each suite.

These are existing service suites, not native UI or phone delivery trials. Each
admin client closes and each disposable runtime is destroyed; its four ports are
independently closed before the next trial. Only the last two suites separately
record Firestore-client termination; no such field is invented for the first
three. Selected source bytes are archived, but legacy suite wrappers do not
independently bind source before and after build. Whole-head attestation is false.

The separate 19-checkpoint current-account registration recheck covers the new
stale-login and disabled-account refusals. This regression bundle preserves the
older working team flows rather than replacing that recheck. No real provider
send, token, payment, map request, production write or release acceptance is added.
There is no new public media, changed phone date, tour or status.
