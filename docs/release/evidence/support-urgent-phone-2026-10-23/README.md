# Urgent Support: Connected Physical Trial

23 October 2026. One disposable physical Android phone connects only to the
isolated local `demo-sgm-local-qa` fixtures. This does not activate production.
The APK hash and unchanged native source are pinned in `summary.json`.

Observed through the native app: prepare Urgent, submit once, read the received
request, read the actual support reply, refresh the closed request, reopen it,
sign into another account with an empty history, then restore the original
account and its closed request with the same single reply.

The actual management browser receives the urgent alert without reload. Review
with an empty note, written reply and Close are all performed through its forms,
not written by a service helper. The alert disappears after closure. Email status
truthfully remains unconfigured; no provider request or real email is sent.

All eight independent read-only record checkpoints pass. They retain one report,
submission identity, support-only outbox and public reply; all 158 baseline records
and actor claims are preserved, except allowed monotonic profile timestamps.
They also verify denied foreign reads and denied club-manager email retry. These
checks do not independently prove a phone screen or operator action.

`originals/` contains unchanged browser-stream contexts and management captures.
`capture-index.json` records their file timestamps and exact unscaled rectangles.
Five reviewed phone rectangles are allowlisted for the local portal. They are not
native-resolution exports. No app content is retouched. The provider screenshot
operation returned to its idle control without an observed download. Recording
explicitly failed to start because the browser lacked screen-sharing permission;
no permission change, browser restart or replacement video is claimed.

Preflight login errors came from visibly incorrect remote text entry. Exact
native clipboard input then authenticated both synthetic accounts. This does not
establish an application authentication defect. No credentials are retained.

Cleanup: native sign-out, provider uninstall acknowledgement, launcher absence,
explicit Stop Session and dashboard observed. The independent observer and owned
helper/backend/management preview exit. The helper group and private directory,
credential file and all five listening ports are verified closed/removed. No
phone administration, store or network settings were changed in this trial.

Real email configuration and receipt, production activation, true network loss,
whole-process restart and general release readiness remain open. Publication is
held while the Site audience is public. Earlier local and physical trials retain
their original dates, outcomes and media.

The updated local portal loads all five tour steps at 1440, 768, 390 and 320 pixels
without horizontal overflow or missing images. Four reviewed unchanged viewport
